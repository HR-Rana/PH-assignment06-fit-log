#  Fit Log

**Fit Log** is a modern and responsive workout tracking web application built with **Next.js, TypeScript, and Tailwind CSS**. It helps users explore different workouts, view detailed exercise information, create a daily workout plan, save workouts for later, and track completed exercises.

###  Features

*  Browse and explore different workouts
*  View detailed workout information
*  Create and manage a **Today's Workout Plan**
*  Save workouts for later
*  Mark workouts as completed
*  Store workout plans and saved workouts using **Local Storage**
*  Fully responsive design for mobile, tablet, and desktop
*  Fast and optimized UI with Next.js
*  Modern interface built with Tailwind CSS
*  Workout information including difficulty, duration, calories, sets, reps, rating, equipment, and muscle groups

###  Technologies Used

* Next.js
* TypeScript
* React
* Tailwind CSS
* Context API
* Local Storage
* REST API


### features of the project:

1) Fit Log – Explore and manage different workout exercises in one place.
2) Workout Details – View complete information about each workout, including difficulty, duration, calories, sets, reps, equipment, and  targeted muscle groups.
3) Today's Workout Plan – Add workouts to your daily workout plan and manage them easily.
4) Save for Later – Save your favorite workouts and access them whenever you need.
Mark as Done – Mark completed workouts and keep your daily plan organized.
5) Local Storage – Save today's workout plan and saved workouts in the browser using Local Storage.
6) Responsive Design – Fully responsive interface for mobile, tablet, and desktop devices. 



###  Purpose

The goal of Fit Log is to provide a simple and user-friendly platform where users can discover workouts and organize their daily fitness routines in one place.
